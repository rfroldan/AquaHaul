AQUA HAUL 
Individual 2D Game
CS583 3D Game Programming

Goal:
Collect as many coins as you can per dive, max out every upgrade while avoiding enemies and obstacles. 

The fish will take a life if you collide with them; The bomb will instantly kill you no matter how many lives you have. 
When you die you lose the coins you collected during that current dive, but you keep the coins from previous dives that 
have not been spent. 

Controls:
↑ - Up
↓ - Down
← - Left
→ - Right
Space - Dodge (when unlocked)

Available Upgrades:
  - Oxygen Tank
  - Flippers
  - Divers Suit
  - Dodge
